# Pacific Softcom (PSC2)

Landing page for Pacific Softcom Inc., a certified 3CX partner in Long Beach, CA.
PSC installs and supports 3CX phone systems, SIP trunking, hotel PMS phone
integration and remote office phones. Brand line: "Cut the phone bill. Keep the phones."

## What's here

```
index.html          The site. Generated by build.ps1. Open it or serve it.
assets/             Logos and favicons.
src/                Sources the site is built from. Edit these, not index.html.
wordpress-theme/    The same site as an installable WordPress theme (PHP).
docs/WIREFRAME.md   The original conversion wireframe.
build.ps1           Rebuilds index.html and regenerates the theme.
.nojekyll           Tells GitHub Pages to serve assets/ verbatim.
```

## View it locally

Open `index.html` in a browser. For the fonts to load reliably, serve it over
HTTP rather than the `file://` protocol:

```bash
# Python 3
python -m http.server 8000
# then visit http://localhost:8000
```

## Host it on GitHub Pages

1. Push this folder to a GitHub repository (see below).
2. In the repo, go to **Settings > Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick
   the `main` branch and the `/ (root)` folder, and save.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/` within
   a minute or two.

The folder is already a git repository with one commit on `main`, so you only
need to add the remote and push:

```bash
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

`index.html` is at the repo root and every path in it is relative, so Pages
serves it as the home page with no extra configuration, including from a
`/<repo-name>/` sub-path.

## Editing the site

`index.html` is generated with all CSS and JS inlined, so do not edit it by hand.
Edit the sources instead:

```
src/_head.html      <head> contents: title, meta, favicons, fonts, structured data
src/_body.html      Page markup
src/css/theme.css   All styles
src/js/main.js      All interaction (estimator settings live in calcConfig at the top)
```

Then rebuild:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

That regenerates `index.html`, and also rewrites `wordpress-theme/style.css`,
`wordpress-theme/front-page.php` and `wordpress-theme/assets/js/main.js` from the
same sources and copies `assets/images` into the theme, so both deliverables stay
in step. `functions.php` and `index.php` are edited in place.

## The WordPress theme

`wordpress-theme/` is a self-contained theme (`style.css`, `front-page.php`,
`functions.php`, `index.php`, `screenshot.png`, `assets/`). GitHub Pages ignores
it because Pages does not run PHP. To use it, copy the folder into a WordPress
install under `wp-content/themes/`, activate it, then set a static front page
under **Settings > Reading**.

In WordPress the bill review form and the call-back form post to
`admin-post.php` and email the lead with `wp_mail`. An attached phone bill (PDF,
JPG, PNG or HEIC, 10 MB max) goes out as an email attachment and is deleted from
the server straight after. The destination address defaults to
PSC@Pacificsoftcom.com and can be changed under **Settings > General > PSC lead
email**. Make sure the host can send mail (an SMTP plugin is the usual fix).

## Notes

- The static site has no server, so on GitHub Pages both forms open the
  visitor's email app with the request filled in. Browsers can't attach a file
  to a `mailto:` link, so the success message asks the visitor to attach their
  bill in that email. The WordPress theme uploads it for real.
- No video or photos. The hero and final call-to-action backgrounds are a
  code-drawn call network on a canvas that pauses when off screen.
- Fonts (Familjen Grotesk, Figtree, JetBrains Mono) load from Google Fonts, so
  the live site needs an internet connection for the intended typography.
- The supplied logo has a black wordmark that disappears on the navy header.
  `assets/images/psc2-logo-white.png` is a generated variant with the wordmark
  recoloured white and the teal arcs untouched. The original is
  `psc2-logo.png`, used once the header turns white on scroll.
- Favicons (`favicon.ico`, 16/32 px, Apple touch icon, 192/512 px) were all
  generated from the supplied PSC2 Favicon.png.
- Motion respects `prefers-reduced-motion`: the custom cursor, network
  animation, word reveal, count-ups, marquee and scroll reveals are off or
  static.
